## 正式适配的边界

本次证明：已加载该插件的原终端进程存在可用的双向控制接口。证明范围不包含“任意已经运行的会话无需加载插件即可接管”。

正式实现应采用 Claude 专用适配器复用现有会话 UI 和安卓通知，同时加入真实状态重建、消息来源及回执映射。终端 Esc 后的输入限制必须在 UI 提示，不应通过 resume/fork 冒充接管成功。热加载中的轮次识别、计划/提问/沙箱交互、并发子代理与外网移动端，需要后续单独验证。
