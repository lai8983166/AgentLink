ALAgentLink · UI 原型

手机端「完整驾驶舱」· 第一版以 Codex 为主 · Raft 风皮肤

导览 · 可以点什么

  1. 顶部横幅：待审批告警 → 点击直达会话内的审批卡片
  2. 会话卡片：进入对话流（第一个是审批场景）
  3. 工具卡片：点开可展开输出；diff 卡片点开全屏 diff
  4. 审批卡片：批准 / 拒绝，观察横幅和状态条的联动
  5. 右下角 ＋：开新任务（选项目、审批策略、输入需求）
  6. ⚙ 设置：连接、通知、安全与审计日志

设计原则

  1. 审批一步到位——通知 → 直达 → 一次点击，这是全 app 最短路径
  2. 可扫读优先——工具调用默认折叠成一行摘要，长输出不淹没对话
  3. 当前动作常显——不读全文也知道 agent 在干嘛
  4. 通知驱动闭环——派任务 → 收通知 → 回来处理，不用盯屏

视觉风格 · Raft

  1. 参照 raft.build：暖米白纸底 + 金黄 #FFD700 主色 + 墨色描边与硬投影，千禧年聊天室质感
  2. 字体 Space Grotesk / Space Mono（CDN 加载，离线回退系统字体）
  3. 等待审批直接用品牌金黄——它是全 app 最重要的事
正式实现：React + Vite 的 PWA（Android 主目标），由 daemon 托管。设计推导的 API 契约草案见 design/ui-design.md。本原型为纯静态 mock，无 JS 依赖。
